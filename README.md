# RotaLab — Simulador e painel de gestão logística

Projeto didático independente para treinar programação de fretes, utilização de frota e análise financeira com dados fictícios.

## Acessar
- **Simulador de treinamento:** https://kennidyroger04-wq.github.io/simulador-logistica/
- **Painel de gestão V1:** https://kennidyroger04-wq.github.io/simulador-logistica/gestao/

## Painel de gestão
- 30 veículos e 30 motoristas fictícios, com inclusão de novos cadastros.
- Recebimento e programação manual de ofertas.
- Seleção de veículos compatíveis por carroceria e capacidade, bloqueio de veículo/motorista ocupado.
- Cálculos de diesel, manutenção, depreciação, tributos, comissão e despesas adicionais.
- Controle de andamento e conclusão das viagens em dias simulados.
- Histórico, indicadores financeiros e exportação de CSV.
- Premissas editáveis; armazenamento local no navegador, sem cadastro/login.

## Avisos
Este é um **protótipo para demonstração**, não um sistema de controle de transporte pronto para produção. As ofertas, cidades, distâncias, valores, motoristas e veículos são fictícios. A menção à Votorantim em exemplos **não implica vínculo ou integração**. Não contempla todos os custos, documentos fiscais, cálculo regulatório do piso ANTT, vale-pedágio, habilitações específicas, seguros, jornada, integrações operacionais ou apuração de lucro real. Os dados ficam apenas neste navegador (localStorage): não são compartilhados entre aparelhos e podem ser apagados ao limpar os dados do site.

Para reiniciar: Painel de gestão → Ajustes → Restaurar dados fictícios.
